# Nexus Frontend

Frontend-часть приложения **Nexus**, обеспечивающая пользовательский интерфейс и взаимодействие с системой.

## 🚀 Основные возможности

- 🔐 Регистрация и авторизация
- 👤 Просмотр и редактирование профиля пользователя
- 🎯 Просмотр персональных рекомендаций
- 🤝 Взаимодействие с пользователями
- 💬 Чат

## 🛠 Технологии

- **React**
- **TypeScript**

## 📁 Структура проекта

```text
src/
├── api/          # Взаимодействие с Backend API
├── components/   # Переиспользуемые UI-компоненты
├── hooks/        # Пользовательские React-хуки
├── pages/        # Страницы приложения
└── store/        # Управление состоянием приложения
